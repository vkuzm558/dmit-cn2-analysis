## CN2、CN2 GIA、CN2 GT 到底有什么区别？

很多人分不清这几个概念，简单说一下：

| 线路类型 | 说明 | 体验 |
|---------|------|------|
| 普通 BGP | 标准互联网路由，走公共交换节点 | 高峰期容易拥堵，丢包明显 |
| CN2 GT（Global Transit）| 中国电信 CN2 过渡版，部分节点走 CN2 | 比 BGP 好，但晚高峰也会堵 |
| CN2 GIA（Global Internet Access）| 中国电信最高级别专属线路，全程直连 | 延迟低，高峰期依然稳定 |

CN2 GIA 的核心优势在于**双向优化**——不只是出去的流量走优质路由，回程也走同等级别的线路。这对于大多数用户来说体感最明显，因为你访问 VPS 上的内容，走的是"回程"。

DMIT 的 Premium 系列就是主打 CN2 GIA，三大运营商分别优化：
- **中国电信**：CN2 GIA（AS4809），专属高速通道
- **中国联通**：AS9929（CUII，联通政企精品网）
- **中国移动**：CMI（AS58807，移动国际出口）

三网都走顶级线路，这就是为什么很多人愿意为 DMIT 多付一些钱。
